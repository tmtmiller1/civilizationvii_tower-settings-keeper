# Steam Workshop assets

Everything here is set by hand on the Workshop page. The manifest `dist/workshop_item.vdf` carries no preview file,
because steamcmd rejects one sent that way.

- Preview image: `docs/workshop-preview.png` (1024x1024, rendered from `docs/workshop-preview.svg`; also copied to
  `dist/preview.png` by `release.sh`).
- Description: `docs/steam-workshop-description.txt` (BBCode, no blank lines).
- Change note: `CHANGELOG.steam.txt`, generated by `release.sh` from `CHANGELOG.md`.

Screenshots, 1600x1000 JPEG with all metadata stripped, in upload order, with the caption to give each one. The full-size captures are in
`originals/`.

| File | Caption |
|---|---|
| `01-main-menu-options-after-restart.jpg` | Options, Add-ons from the main menu after a restart. Every value shown here was set in the previous session and read back. |
| `02-in-game-options-after-restart.jpg` | The same screen from inside a game after another restart, values still in place. |
| `03-commander-lens-from-the-saved-setting.jpg` | Other mods act on the saved values. Commander lens activation was saved as Military and Recon Units, so selecting a scout in a new session opens the commander lens. |
| `04-storage-limit-row.jpg` | The Storage limit reached row, shown only after a mod tried to store more than the 4 MB cap. |
| `05-storage-limit-dialog.jpg` | Its dialog names the mod and the sizes. OK clears the notice. |
| `06-rebuild-storage-row.jpg` | The Rebuild storage row, shown only when the store held entries the mod could not identify. |
| `07-rebuild-storage-dialog.jpg` | Its confirmation says how many entries will go. Every mod's settings are kept. |
