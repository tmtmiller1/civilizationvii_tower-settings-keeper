# Tower Settings Keeper

Мод для Civilization VII. С ним настройки, которые вы задаёте в других модах, сохраняются после перезапуска игры. У него нет собственных настроек, и он не меняет игровой процесс.

## В чём проблема

Моды хранят свои настройки в `localStorage` игры. В Civilization VII 1.5.0 это хранилище работает с ошибкой. Чтение возвращает первую запись хранилища, какую бы запись ни запросили, а получить список записей невозможно. Мод может прочитать свои настройки только тогда, когда его запись случайно оказалась первой. Любой другой мод получает данные чужого мода, принимает их за свои и при следующем сохранении записывает их под своим именем.

Игроки видят панели настроек, которые сбрасываются при каждом запуске, а иногда настройки одного мода появляются внутри другого.

Большинство панелей настроек используют одну общую запись `modSettings` с отдельным разделом для каждого мода. Около пятидесяти модов из Мастерской к тому же содержат вспомогательный код, который стирает всё хранилище, как только видит вторую запись. Достаточно одного мода, хранящего настройки в собственной записи, чтобы при следующем сохранении пропали настройки всех остальных.

## Что делает мод

Он хранит все записи внутри единственной строки, которую игра умеет читать, и отвечает на каждый вызов `localStorage` из этой строки.

- Мод, использующий собственный ключ, получает его сохранённым и прочитанным под этим ключом.
- Общая запись `modSettings` работает как прежде, по разделу на мод, поэтому существующие панели настроек менять не нужно.
- Хранилище всегда сообщает об одной записи, поэтому стирающий код никогда не срабатывает.
- Если другой мод уже нарушил порядок в хранилище, мод ставит на место записи, которые может опознать, а остальные не трогает. Он проверяет это заново при каждом запуске.

Другим модам не нужны обновления. Мод работает с модами, которые уже есть в Мастерской.

## Работает с любым модом, без изменений

Этот мод решает проблему для всех модов, хранящих настройки, в их нынешнем виде. Авторам модов не нужно ничего менять или регистрировать. Игрок, установивший этот мод, сразу получает работающие настройки во всех своих модах.

У авторов модов есть дополнительная возможность. Они могут положить тот же файл в свой мод, чтобы их игроки были защищены, даже если никогда не установят этот мод. Это описано ниже в разделе «Авторам модов». Мод с этим файлом и этот мод можно установить вместе. Работает только одна копия, самая новая, остальные ничего не делают.

## Установка

Подпишитесь в Мастерской Steam или скачайте zip последнего выпуска и распакуйте его в `~/Library/Application Support/Civilization VII/Mods/` (macOS) или `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods\` (Windows). Затем включите мод в разделе «Дополнительный контент». Настраивать ничего не нужно.

## Полезно знать

- Настройки, сохранённые с этого момента, остаются. Настройки, потерянные до установки мода, пропали, если только они не лежат на диске в записи, которую мод может опознать.
- Если хранилище уже было испорчено, мод не гадает, какой мод записал запись, которую он не может опознать. Если эта запись единственная оставшаяся, мод перестраивает хранилище вокруг неё и сохраняет её содержимое. Имя записи теряется. Более поздняя версия, распознав содержимое, вернёт его под правильное имя. Если впереди две такие записи или больше, мод создаёт перед ними новый корень, оставляет их на диске и пробует снова при следующем запуске. Он никогда не перезаписывает данные другого мода.
- Игра не гарантирует порядок выполнения скриптов модов. Мод, который читает свои настройки в момент загрузки своего скрипта, до того как выполнится этот мод, при этом одном запуске видит прежнее поведение. Во всех тестовых запусках до сих пор этот мод выполнялся первым.
- Собственные тексты мода переведены на все одиннадцать языков, которые поддерживает игра.
- У хранилища есть предел размера в 4 МБ. Это в восемь раз больше 0,5 МБ, которые занимает хранилище с 28 модами. Моду, который пытается его превысить, отказывают в этой одной записи, его прежние настройки сохраняются, а в «Настройки, Дополнения» появляется строка «Достигнут предел хранилища» с именем мода. Больше ничего не затрагивается. См. «Нагрузка и пределы» ниже.
- На экране ничего не появляется, кроме одной строки в `Logs/UI.log`, начинающейся с `[settings-keeper] ready:`. Исключение: описанный выше резервный случай. Тогда в «Настройки, Дополнения» появляется строка «Перестроить хранилище». Нажмите её, подтвердите, и записи, которые мод не смог опознать, будут удалены, а хранилище записано заново одной записью. Строка исчезает, когда хранилище приходит в норму.

## Нагрузка и пределы

Всё лежит в одной строке, поэтому следить нужно за размером этой строки. С 28 установленными модами строка на тестовой машине занимает около 0,5 МБ, почти целиком это история партий одного мода. Панель настроек добавляет несколько сотен байт. Запись сериализует всю строку, около 8 мс при таком размере, один раз за задачу независимо от числа записанных в ней значений. Само число модов не имеет значения. Важно, сколько они хранят.

Чтобы найти, где движок сдаётся, зонд увеличивал строку на 1 МБ за шаг через этот мод в партии «Играть сейчас» с теми же 28 модами, а отдельные запуски проверяли каждую часть по отдельности.

| Размер строки | Одна запись (сериализация и сохранение) | Чтение одного ключа после записи |
|---|---|---|
| 0,5 МБ, реальное хранилище | 8 ms | 2 ms |
| 5 MB | 71 ms | 20 ms |
| 10 MB | 101 ms | 64 ms |
| 13 MB | 141 ms | 67 ms |
| 16 МБ одной записью | 102 ms | |
| 20 МБ, рост по 1 МБ | 197 ms | |

Ни при каком размере ничего не потерялось и не повредилось, и хранилище всё время оставалось одной строкой. Потолок есть у самого процесса игры. Он останавливался без отчёта о сбое на шаге 14 МБ, когда строку несколько раз подряд читали и перезаписывали, и на шаге 21 МБ, когда её только перезаписывали. Хранилище в 14 МБ загрузилось в главном меню и в партии со всеми читаемыми ключами, а затем остановилось, когда строку ещё раз прочитали и перезаписали. При остановке процесс занимал 1,9 ГБ, так что потолок — память игры, а не хранилище.

Поэтому мод отклоняет любую запись, которая увеличила бы строку свыше 4 МБ, четверти наименьшего размера, при котором игра остановилась. Отклонённая запись выбрасывает тот же `QuotaExceededError`, что и браузер при переполнении localStorage, так что мод, написанный под веб-API, уже знает, что это значит. Прежнее значение мода остаётся, остальные моды не затрагиваются, журнал называет мод и размеры, а в «Настройки, Дополнения» появляется строка «Достигнут предел хранилища» с теми же сведениями и кнопкой «ОК», которая её убирает. Предел — одна константа в начале `ui/settings-keeper.js`.

## Удаление мода

Обычно ничего делать не нужно. Хранилище состоит из одной строки, поэтому игра, как и раньше, читает сначала `modSettings`, а другие моды находят свои разделы. Единственное добавление: несколько внутренних полей, которые они игнорируют. Если в «Настройках» видна строка «Перестроить хранилище», нажмите её до отключения мода. Иначе стирающий код в других модах очистит хранилище при следующем сохранении.

## Авторам модов

От вас ничего не требуется. Настройки вашего мода работают при установленном этом моде, использует ли ваш мод общую запись `modSettings` или собственный ключ.

Если вы хотите защитить своих игроков без установки этого мода, вы можете включить исправление в свой мод. Это один файл и две строки в modinfo, а код настроек остаётся прежним. Инструкция находится в [embed/README.md](../../embed/README.md) (на английском), либо возьмите `settings-keeper-embed-<версия>.zip` из последнего выпуска.
